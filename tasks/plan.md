# Home Care UNAI V2 execution plan

## Dependency order

Existing data and pricing -> role state -> customer booking wizard -> caregiver workspace -> responsive styling -> deployment packaging -> browser and live verification.

## Vertical slices

1. Baseline and safeguards: preserve imported source, record design direction, and run existing tests.
2. Caregiver journey: add role switching, assigned schedule, job details, and availability summary.
3. Booking journey: expose five meaningful steps with validation and persistent draft state.
4. Demo integrity: label fictional profiles and reviews, remove unsupported trust language, and preserve receipt disclaimers.
5. Delivery: add Vercel static configuration, CI, README deployment notes, and security exclusions.
6. Verification: run tests/build, inspect desktop/mobile screenshots, click critical workflows, inspect console, push GitHub, deploy Vercel, and verify the public URL.
